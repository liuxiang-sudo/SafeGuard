如何提供训练数据

您可以通过上传标记好的数据集来帮助我们改进人机检测算法。您的数据将用于训练机器学习模型，使其能够更准确地区分人类和机器人。

数据格式要求

我们接受 JSON 和 CSV 格式的数据集。每个样本应包含以下字段：

{
  "samples": [
    {"username": "sample_user", "email": "user@example.com", "bio": "分享生活", "time_to_fill": "45"},
    {"username": "bot_99999", "email": "bot@example.com", "bio": "自动更新", "time_to_fill": "2"}
  ],
  "labels": [0, 1]
}

提示

  • 确保您的数据集包含足够多的样本（至少50个）
  • 保持人类和机器人样本的平衡比例
  • 您可以选择将您的数据与我们的默认数据集混合，以提高模型性能
  • 如果您不确定如何创建数据集，可以下载我们的模板
